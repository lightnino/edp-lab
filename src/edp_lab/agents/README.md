# Offline source observation Agent V0

`analyst_v0` implements the read-only deterministic §2.6 orchestrator over all five
existing typed profiling adapters. No SDK, model or network call is used.
`checkpoint_v0` is the separate explicit offline execution/evaluation host.
`c300_shallow_v0` requires scoped parser authority before shallow mechanical scans.

See `docs/source_observation_agent_v0.md`. C300 admission alone never authorizes
parser activation, and mechanical observations never approve semantic facts.
